# Prashna Tantra (Horary Astrology) Specification

## Query Mechanics
1. Exact timestamp and geographical coordinates of query interrogation.
2. Interaction between **Lagnesha** (Querent) and **Karyesha** (Object of Desire).
3. Application of Tajika aspects: **Ithasala** (Immediate fulfillment), **Ishrafa** (Separation), and **Nakta** (Mediated fruition).
