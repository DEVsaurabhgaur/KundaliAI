# Ashtakavarga Shodhya Pinda & Longevity Mathematics

- **Rashi Pinda**: Sum of reduced bindus multiplied by Rashi constants (7, 10, 8, 4, 10, 5, 7, 8, 9, 5, 11, 12).
- **Graha Pinda**: Sum of occupied bindus multiplied by Graha constants (Sun 5, Moon 5, Mars 8, Mercury 5, Jupiter 10, Venus 7, Saturn 5).
- **Shodhya Pinda** = Rashi Pinda + Graha Pinda.
