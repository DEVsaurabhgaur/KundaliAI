# Vedic Numerology & Ank Jyotish Manual

## The Three Core Pillars
1. **Mulank (Root/Psychic Number)**: Day of birth (1-31) reduced to a single digit (1-9). Represents personal identity and internal subconscious drive.
2. **Bhagyank (Destiny/Life Path Number)**: Full birth date sum (DD+MM+YYYY). Represents karmic destiny, career path, and outer worldly fate.
3. **Namank (Name Number)**: Acoustic numeric vibration of given name using the ancient Chaldean cipher.
